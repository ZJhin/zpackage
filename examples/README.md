# Examples

This folder is reserved for lightweight, reproducible notebooks and scripts.

Recommended future examples:

- `ztake_workflow.ipynb`: catalog search, model/member/grid inspection, and opening local/online CMIP6 data.
- `wmt_density_bins.ipynb`: computing heat/freshwater WMT in sigma0 density bins and plotting model grids.

Keep exploratory scratch notebooks outside the tracked examples folder until they are cleaned and reproducible.
